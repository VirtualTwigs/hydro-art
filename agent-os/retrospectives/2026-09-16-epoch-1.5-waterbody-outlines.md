# Retrospective — Epoch 1.5: Waterbody outlines (W1-W4)

_Closed 2026-09-16. Work spanned 2026-07-29 (W1) through 2026-08-12 (W4 presets
close). The epoch was the first additive feature layer on the 2D pipeline and
established the pattern every subsequent layer (Epoch 15 natural water features,
Epoch 16 hydro structures) followed._

## What the epoch was

Extend the river-only art with accurate outlines for areal water features — lakes,
ponds, reservoirs, bays, inlets, estuaries — drawn as fill-free SVG polygons in
dedicated layers. Classification is FType-driven (not name-matching), selection is
deterministic and threshold-controlled, the conservative coast policy refuses to
close open-ocean or clip-boundary fragments into misleading shapes. The result is
still public-domain USGS data, still deterministic, and still editable in vector
tools.

Four roadmap items: W1 (taxonomy), W2 (selection), W3 (rendering + config), W4
(QA + presets). All four shipped.

## What shipped

### W1 — Source layers & classification (`46a0766`)

`src/waterbodies.py` (new): immutable `WaterbodyFeature` value object, versioned
`FTYPE_CLASS` policy table (v2026-07-29.1) mapping 10 FTypes to 7 classes
(`lake`/`pond`/`reservoir`/`bay`/`inlet`/`coastal`/`excluded`). `src/loading.py`
gained `WATERBODY_LAYER_ALLOWLIST` (`NHDWaterbody`, `NHDArea`) deliberately
separate from `HYDRO_LAYER_ALLOWLIST`, plus `discover_waterbody_layers` and
`PyogrioLayerLoader.load_waterbody_layers`. Pure/offline, no GIS imports, no
pipeline wiring. Tests: `tests/test_waterbodies.py` (7) + `tests/test_loading.py`
(+2). Suite: **159 passing** (+9).

### W2 — Polygon repair, clipping & selection (`86189d8`)

`src/waterbody_selection.py` (new): `process_waterbodies` runs repair (reuses
`src.geometry.repair_geometry`) -> reproject EPSG:5070 -> region clip (reuses
`src.clipping.clip_geometry`) -> area measurement -> policy.
`WaterbodySelectionPolicy` with `min_inland_area_m2` (default 0),
`min_coastal_area_m2`, `pond_max_area_m2`, `coastal_mode` (default
`conservative`). Conservative coast: a coastal-class feature trimmed by the region
clip is excluded as a clip-boundary fragment. `WaterbodySelection` report: every
candidate in exactly one of `selected` / `excluded`; exact-duplicate footprints
de-duplicated via normalized-WKB key; shared coincident boundary segments counted
via STRtree and flagged `shared_edge`. Tests: `tests/test_waterbody_selection.py`
(8). Suite: **167 passing** (+8).

### W3 — Rendering & configuration (`4acbdd4`)

Wired W1/W2 into the live pipeline.

- `src/config.py`: frozen `WaterbodySettings` dataclass, `DEFAULTS["waterbodies"]`
  (on by default, `#2ec4ff`, stroke 0.45, thresholds 0, conservative, below),
  `_coerce_waterbodies` boundary validation.
- `src/cli.py`: `--waterbodies/--no-waterbodies`, `--waterbody-color`,
  `--waterbody-stroke-width`, deep-merge so YAML < CLI holds per sub-key.
- `src/rendering.py`: `polygon_path_d` (one closed `M...L...Z` subpath per ring,
  holes + multipart preserved), `_waterbody_lines` emitting
  `<g id="waterbodies" fill="none">` with per-feature stable IDs + `data-class`.
  `waterbody_order` controls z-order (below/above flowlines).
- `src/pipeline.py`: `validate` additively loads waterbody layers (gated on
  `settings.waterbodies.enabled` AND `hasattr(loader, "load_waterbody_layers")`);
  `generate_svg` classifies -> selects -> renders. `WaterbodySelection` stashed in
  `artifacts["waterbody_selection"]`.

Tests: `tests/test_waterbody_config.py` (8) + `tests/test_waterbody_rendering.py`
(5) + `tests/test_waterbody_pipeline.py` (4), including
`test_disabled_waterbodies_build_is_byte_identical`. Suite: **184 passing** (+17).

### W4 — QA, real-data validation & presets (`110de80`, `fc60c5c`, `82437b9`, `c2ba416`, `7e0cf11`, `9dc4232`)

Three phases:

1. **Offline QA fixtures + real-data harness** (`110de80`/`fc60c5c`).
   `tests/test_waterbody_qa.py` (5): donut hole survival, MultiPolygon rendering,
   conservative-coast end-to-end, shared-edge rendering, `stroke-linejoin="round"`
   / `stroke-linecap="round"` on the `waterbodies` group. `tools/waterbody_qa.py`
   (new, non-offline): real-data QA harness reusing the pipeline's classify +
   `process_waterbodies`, with Census county/state clip support. Suite: **189
   passing** (+5).

2. **Preset mechanism** (`82437b9`). `WATERBODY_PRESETS` in `src/config.py`,
   `_coerce_waterbodies` pops a `preset` directive and layers
   `defaults < preset < explicit`. `--waterbody-preset` CLI flag
   (`choices=SUPPORTED_WATERBODY_PRESETS`). Nested `waterbodies` merge base changed
   from `dict(DEFAULTS["waterbodies"])` to `{}` — behavior-preserving since
   `_coerce_waterbodies` fills defaults. Suite: **443 passing** (+8 in
   `test_waterbody_config.py`, now 16 total there).

3. **Scale-specific presets** (`7e0cf11`/`9dc4232`). The Clark County real-data QA
   (`c2ba416`) proved the provisional `print` preset (100k/250k m^2) was too
   aggressive at county scale (830 -> 24, a 97% drop). Split into `print-state`
   (100k/250k m^2, whole-state/large-format) and `print-county` (25k/50k m^2,
   single-county). Tests: `tests/test_waterbody_config.py` updated, monotonic-
   thinning invariant added (screen keeps more than print-county keeps more than
   print-state).

**Total waterbody-specific tests at epoch close: 46** (7 + 2 loading + 8
selection + 17 config + 5 rendering + 4 pipeline + 5 QA = 48 touched files; 46
in the six `test_waterbody_*` files per current suite).

## Real-data findings

### Oregon + Washington statewide (`fc60c5c`, 2026-07-30)

Ran `tools/waterbody_qa.py --state {Oregon,Washington}` against local extracted
NHDPlus HR (basins 1701-1712, 161,744 candidate polygons each).

| Metric | Washington | Oregon |
|--------|-----------:|-------:|
| Candidates | 161,744 | 161,744 |
| Selected | 42,304 | 46,844 |
| Excluded | 119,440 | 114,900 |
| Lakes / reservoirs | 39,934 / 2,272 | 45,140 / 1,661 |
| Coastal kept (bay/inlet/coastal) | 98 | 43 |
| Coastal fragments dropped | 99 | 23 |
| Holes (features with holes) | 2,781 (682) | 2,491 (679) |
| Multipolygons | 7 | 6 |
| Duplicate geoms dropped | 9 | 4 |
| Shared-edge pairs | 162 | 388 |
| Untraceable selected | 0 | 0 |

No accidental coast closure. Conservative policy excluded 99 (WA) / 23 (OR)
coastal clip-boundary fragments while retaining genuine bays/inlets/coastal water.
Holes and multipolygons survived selection. Every selected feature carried a source
id.

### Clark County, WA county-level (`c2ba416`, 2026-08-12)

6,416 real candidate polygons from HUC4 1708. County-level clip unblocked by
staging Census `cb_2023_us_county_500k.shp` at `/tmp/counties_shp/`.

| Thresholds | Selected | Breakdown |
|------------|----------|-----------|
| screen (0 / 0 m^2) | 830 | 809 lakes, 21 reservoirs |
| print (100k / 250k m^2) | 24 | 22 lakes, 2 reservoirs |
| print-county (25k / 50k m^2) | ~62 | readable at county zoom |
| print-state (100k / 250k m^2) | 24 | appropriate at state scale |

The Clark run is what proved the single `print` preset was wrong and drove the
`print-state` / `print-county` split. At county zoom, the state thresholds
over-prune (830 -> 24 is a 97% drop); at 25k/50k m^2 the map keeps ~62
waterbodies — visually readable without clutter.

### No "bug the real run surfaced"

Unlike Epochs 8 (mosaic-before-warp resolution drift), 14 (silent truncation),
and 16 (intersects-vs-coincidence-fraction), no code bug was found exclusively by
real data. The conservative coast policy worked as designed on the first real run.
What real data *did* surface was an **art-direction insight** — the single `print`
preset was too aggressive at county scale — which is a tuning lesson, not a code
fix. This is consistent with the epoch being the *first* additive layer: the seam
design (injectable loader, gateable pipeline load, byte-identical-when-off) was
proven here and reused by two later epochs without structural bugs.

## Invariants held

- **Offline suite:** 46 waterbody-specific tests; full suite green throughout
  (159 -> 167 -> 184 -> 189 -> 443 at each milestone). Current full suite: 1027
  passing. No GDAL, no network, no real data in the suite.
- **2D default output byte-identical:** yes. `waterbodies.enabled` defaults to
  `True`, but with a river-only loader (the offline/test path) `render_svg`
  receives `waterbodies=None` and returns identical bytes. The `validate` stage
  skips waterbody loading unless the loader supports it AND the setting is enabled.
  `test_disabled_waterbodies_build_is_byte_identical` guards this.
- **`PIPELINE_STAGES` untouched:** yes. No stage added or reordered. The additive
  load lives inside the existing `validate` stage, gated on setting + loader
  support. This established the pattern Epochs 15 and 16 followed.
- **Rights gate:** N/A — NHDPlus HR waterbody polygons are USGS federal public
  domain, same as flowlines. Sellable with attribution.
  `fulfillment.assert_sellable` is unaffected.

## Graded against pre-analysis

`planning/requirements.md` served as the pre-analysis (no separate
`pre-analysis.md` file). Four decisions were resolved before implementation:

1. **Enablement: on by default** — shipped as planned. The gated loader pattern
   means "on by default" only affects builds where waterbody data is present.
2. **Inland threshold: 0 (keep all valid)** — shipped as planned. Clutter control
   deferred to presets, which shipped in W4.
3. **Color: single distinct water color** — shipped (`#2ec4ff`), independent of
   watershed palette. Never touched watershed coloring.
4. **Coast: conservative** — shipped as designed. The first real run (OR + WA)
   confirmed it drops clip-boundary fragments while keeping genuine coastal water.
   No false closures.

The spec's acceptance criteria (fixture tests for class/threshold/hole/multipart/
deterministic-ID/no-fill; real Clark County validation; waterbody config affects
only waterbody layers; default builds unchanged) were all met. The only partial
result: Clark County county-level clip was deferred from the W4 offline slice
(2026-07-30) to the preset phase (2026-08-12) because the Census shapefile wasn't
initially staged.

## Carry-forwards

- **Preset values are tunable, not final.** The `print-state` (100k/250k m^2) and
  `print-county` (25k/50k m^2) numbers are backed by the Clark QA run but not by
  a systematic multi-county review. They're labeled as defensible defaults, not
  art-direction gospel.
- **Full byte-identical build compare was not run with GDAL.** The invariant is
  held by `test_disabled_waterbodies_build_is_byte_identical` in the offline suite
  and by the gated-loader architecture, not by a live `verify_determinism.py`
  double-render. This was a shared carry-forward at Epoch 1.5 close; it was
  eventually resolved by `verify_determinism.py --region Oregon` in Epoch 16's
  #67 (svg sha `e6b9bd6cfaf7...`, 0 structures on the default path).
- **Waterbody + county clip needs Census shapefiles staged.** The harness supports
  `--county-shp --county Clark --state-fp 53` but the shapefiles are not
  repo-tracked; they must be staged at `/tmp/counties_shp/` (or equivalent).

## Lessons

- **The additive-layer pattern works and scales.** Gated pipeline load (setting
  AND loader support), byte-identical-when-off, dedicated SVG group with stable
  IDs, waterbody-specific tests alongside pipeline-integration tests. Epochs 15
  and 16 reused this pattern with zero structural changes to the pipeline
  integration mechanism.
- **Ship the mechanism, tune the values separately.** The W4 preset mechanism
  shipped before the final numbers were known. This let the Clark County QA drive
  the `print-state` / `print-county` split as an incremental value change, not a
  replumbing. The pattern was reused for `WIDTH_PRESETS` and
  `HYDRO_STRUCTURE_PRESETS`.
- **Real data surfaces art-direction insights, not just bugs.** The Clark County
  97% drop (830 -> 24) was invisible in fixtures. Not every real-data finding is a
  code fix; some are product decisions that need a human eye.
- **Conservative coast policy was right.** Defaulting to omission over misleading
  geometry (the spec's explicit framing) paid off: zero false coast closures across
  161,744 candidate polygons per state, and the 99/23 dropped fragments were all
  genuine clip-boundary artifacts.

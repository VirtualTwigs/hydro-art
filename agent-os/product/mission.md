# Product Mission

## Pitch

Hydrographic Vector Art Generator is an automated GIS-to-vector pipeline that helps artists, cartographers, and data-visualization enthusiasts produce museum-quality, wall-printable river maps by turning public hydrography datasets into clean, editable, neon-colored SVG artwork with a single command.

## Users

### Primary Customers

- **Print & wall-art creators:** People who want large, original, geographically accurate river artwork suitable for high-resolution printing.
- **Cartographers & GIS practitioners:** Professionals who need reproducible, deterministic hydrographic renderings without manual GIS editing.
- **Data-viz designers & developers:** Designers who want editable vector output they can refine in Illustrator, Affinity, Figma, or Inkscape.

### User Personas

**Vector Artist / Print Seller** (28-55)
- **Role:** Independent designer or print-shop operator
- **Context:** Sells large-format nature/map art; needs original works free of copyright risk
- **Pain Points:** Existing "river map" art is traced/copied and legally risky; manual GIS work is slow and non-reproducible
- **Goals:** Generate original, high-detail, print-ready river art on demand for any region

**GIS Analyst / Cartographer** (25-50)
- **Role:** Geospatial professional or hobbyist
- **Context:** Works with USGS hydrography data and needs consistent, repeatable visual output
- **Pain Points:** Hydrography datasets are large, messy, and require geometry repair, reprojection, and clipping before they render cleanly
- **Goals:** A deterministic pipeline that downloads, cleans, and renders hydrography with no hand-editing

## The Problem

### Original hydrographic art is hard to produce legally and reproducibly

Popular colorful river maps are visually striking, but most reproductions trace or copy existing artwork, creating copyright exposure. Producing an original version by hand requires downloading gigabytes of GIS data, repairing invalid geometries, reprojecting, clipping to a region, and rendering — a slow, error-prone, non-reproducible process.

**Our Solution:** Construct entirely original artwork directly from public hydrographic datasets through a fully automated, reproducible pipeline that requires no manual GIS editing.

### Hydrography data is not render-ready

Public datasets (NHDPlus HR, NHD, WBD) contain invalid polygons, self-intersections, mixed projections, and millions of segments that overwhelm naive tooling.

**Our Solution:** An automated validate → repair → reproject → clip stage that normalizes data into a render-ready form before any drawing occurs.

## Differentiators

### Original-by-construction, not traced

Unlike tools or artists that trace existing maps, we build artwork directly from public USGS/hydrography data. This results in genuinely original works with no copyright exposure and full geographic fidelity.

### Deterministic and reproducible

Unlike ad-hoc GIS-plus-illustration workflows, we guarantee identical output from identical inputs via deterministic watershed coloring and a fixed pipeline. This results in trustworthy, versionable, re-runnable art generation.

### Infinitely scalable, editable output

Unlike raster exports, our primary deliverable is a layered, editable SVG that stays crisp at any print size and remains fully editable in professional vector tools.

## Key Features

### Core Features

- **Automated dataset acquisition:** Discovers, downloads, resumes, verifies, and caches public hydrography datasets with no manual fetching.
- **Geometry normalization:** Automatically validates and repairs invalid geometries, then reprojects and clips data to the selected region.
- **Hydrography graph & watersheds:** Builds a directed river network graph and computes selectable HUC watershed groupings and stream ordering.
- **Deterministic basin coloring:** Assigns high-contrast neon colors to adjacent watersheds via graph coloring, never random.
- **Layered SVG rendering:** Produces a clean, watershed-grouped, editable SVG on a black background at publication quality.

### Advanced Features

- **Multi-format export:** Optional PDF, PNG (up to 65536px with tiling), TIFF, and EPS outputs from the same source.
- **Optional glow modes:** Pure-vector or SVG Gaussian-blur glow with configurable radius for neon aesthetics.
- **Configurable scope & styling:** YAML/CLI control of region, projection, stream hierarchy, palette, line width, and outputs, extensible to new regions with minimal change.

### Collaboration Features

- **Reproducible builds:** Single-command runs that produce identical results from identical inputs, so outputs can be shared, versioned, and regenerated by anyone.
